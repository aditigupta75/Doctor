# Dr. Vaibhav Gupta Portfolio

Static single-page portfolio ready for Vercel deployment.

## Deploy to Vercel

1. Upload this folder to a GitHub repository.
2. Import the repository in Vercel.
3. Leave the framework preset as **Other** and do not set a build command or output directory.
4. Deploy. The root URL is routed to `dr-vaibhav-gupta.html` by `vercel.json`.

## Environment variables

No environment variables are required. See `.env.example`; do not create or add secrets unless server-side functionality is introduced.
